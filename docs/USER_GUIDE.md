# Руководство пользователя

## Назначение
Приложение формирует перечень сигналов АСУ ТП для электрических подстанций и выгружает результат в Excel с листами **AI**, **DI**, **DO**.

## Установка и запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите приложение:
   ```bash
   streamlit run app.py
   ```

## Работа с проектом
1. Нажмите **«Добавить присоединение»** и заполните поля:
   - Наименование присоединения.
   - Класс напряжения (кВ).
   - Тип присоединения.
2. Для выбранного типа укажите количество коммутационных аппаратов (КА).
3. Повторите шаги для всех присоединений.

### Сохранение и загрузка
- **Сохранить проект** выгружает JSON-файл с введёнными данными.
- **Загрузить проект** восстанавливает данные из JSON.

## Валидация
Перед выгрузкой Excel приложение проверяет:
- пустые наименования;
- отсутствие выбранного типа;
- отсутствие шаблонов сигналов или КА.
Ошибки и предупреждения отображаются в блоке «Проверки».

## Статистика сигналов
В блоке «Статистика сигналов» отображаются количество сигналов AI/DI/DO и суммарное значение по всем присоединениям.

## Выгрузка Excel
После заполнения данных нажмите **«Сформировать Excel»**, затем скачайте файл **signals.xlsx**.

## Структура шаблонов
Файлы шаблонов находятся в каталоге `config/`:
- `ai_templates.json` — перечни сигналов AI для каждого типа присоединения.
- `connection_apparatus.json` — перечни коммутационных аппаратов и диапазоны количеств для типов присоединений.

При необходимости можно редактировать шаблоны вручную.
