# Руководство пользователя

## 1. Назначение
Программа предназначена для автоматического формирования перечня сигналов АСУ ТП в формате Excel (листы AI, DI, DO) на основе выбранных типов присоединений и шаблонов в конфигурации.

## 2. Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите приложение:
   ```bash
   python src/app.py
   ```

## 3. Работа в приложении
1. Введите **класс напряжения** (например, 110 кВ) и **количество присоединений**.
2. Нажмите **Добавить класс** — появятся строки для ввода присоединений.
3. Для каждой строки заполните:
   - **Наименование присоединения**.
   - **Тип присоединения** (из выпадающего списка).
   - При необходимости снимите галочки **AI/DI/DO**.
4. Нажмите **Сформировать Excel**, выберите имя файла.

## 4. Сохранение и загрузка проекта
- **Сохранить проект** — сохраняет введённые данные в JSON.
- **Загрузить проект** — загружает ранее сохранённый JSON.

## 5. Настройка шаблонов
Шаблоны сигналов находятся в папке `config` и могут быть разбиты на несколько JSON-файлов.
- Все файлы `*.json` в папке `config` объединяются при запуске приложения.
- Раздел `types` содержит типы присоединений и список сигналов для AI/DI/DO.
- Раздел `defaults` содержит значения по умолчанию, которые применяются к каждому сигналу.

## 6. Проверки перед выгрузкой
При формировании Excel выполняются проверки:
- пустое имя присоединения;
- не выбран тип присоединения;
- тип отсутствует в конфигурации.
Если есть ошибки, выводится сообщение, Excel не создаётся.
