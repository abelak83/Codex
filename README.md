# Генератор перечня сигналов АСУ ТП

Приложение формирует перечень сигналов AI/DI/DO в Excel на основе выбранных типов присоединений и конфигурации шаблонов.

## Быстрый старт
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите приложение:
   ```bash
   python src/app.py
   ```

## Документация
- Руководство пользователя: [docs/USER_GUIDE.md](docs/USER_GUIDE.md)

## Конфигурация
Шаблоны сигналов настраиваются в `config/templates.json`.
